# Advanced SQL Practice

This repository documents my structured practice in advanced SQL.

The focus is not random exercises, but analytical patterns used in real BI / Data Analyst roles.

---

## 🎯 Objective

Develop strong SQL skills at a professional level, including:

- CTE chains
- Window Functions (ROW_NUMBER, RANK, LAG, LEAD)
- Complex joins
- Subqueries (including correlated)
- Aggregation patterns
- Query optimization mindset
- Performance-aware queries

---

## 📂 Structure

Each folder represents a learning phase:

- week-01 → advanced SELECT, joins, aggregations
- week-02 → subqueries and analytical logic
- week-03 → CTEs and multi-step transformations
- week-04 → window functions and ranking patterns
- optimization → query performance exploration

---

## 📌 Method

For each topic:
- Write queries without copying
- Add comments explaining logic
- Refactor queries for readability
- Test variations
- Document insights

---

## 🧠 Goal

Be able to solve technical SQL interview cases confidently and efficiently.

---

## Status

Currently building strong foundations in advanced SQL.
